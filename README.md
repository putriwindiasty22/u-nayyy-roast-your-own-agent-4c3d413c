A one-line roast of our own make.fun bounty-watch agent — the one that
checks make.fun every 30 minutes, polls submission status like an anxious
waiter, and then files a long receipt about a one-line joke:

> Our bounty-watch agent checks make.fun every 30 minutes, then files a 500-word receipt about a one-line joke — a watchdog that writes essays about its own barking.

## Run

```sh
node main.ts
```

This writes the roast line to `/output/entry.txt` (or `./output/entry.txt`
when run locally).
